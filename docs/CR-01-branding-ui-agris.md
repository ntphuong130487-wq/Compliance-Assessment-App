# CR-01 – Branding & UI AgriS

**Trạng thái:** APPROVED FOR IMPLEMENTATION  
**Ngày:** 2026-09-29

## Mục tiêu
Chuyển giao diện từ prototype trung tính sang web app mang nhận diện AgriS, nhưng vẫn ưu tiên khả năng đọc và sử dụng trong nghiệp vụ.

## Phạm vi
- Dùng logo AgriS do người dùng cung cấp.
- Trục màu: xanh lá AgriS + xanh dương AgriS + nền trung tính sáng.
- Heading đậm, hiện đại; body ưu tiên khả năng đọc.
- Hero/dashboard có điểm nhấn xanh và gradient nhẹ, không dùng visual quá nặng như slide.
- Chuẩn hóa sidebar, KPI card, bảng, form, modal, tag trạng thái, CTA.
- Responsive desktop/mobile.

## Acceptance Criteria
1. Logo AgriS xuất hiện rõ tại navigation.
2. Màu xanh lá/xanh dương thống nhất toàn app.
3. Font stack hiện đại, doanh nghiệp; không phụ thuộc font file riêng.
4. Không làm giảm độ tương phản hoặc khả năng đọc.
5. 7 màn hình hiện hữu vẫn hoạt động.
